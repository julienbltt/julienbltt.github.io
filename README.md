# Julien's Github Home Page

Affichage des dépôt github en affichant leur nom, leurs description, license, langage de prog majoritaire et dernière mise à jour.
Bouton d'affichage des détailles qui affiche le README.md.
Bouton d'aller directement au dépôt.
Button pour copier le lien du dépôt.

Utilisation de la librairie 98.css ou 7.css pour l'affichage.
Adapté à la taille d'un écran lambda et d'un télphone.
